# ya_imap

Скрипт создаёт правила обработки писем в Яндекс Почте по таблице Excel. Для каждой строки таблицы получается правило: если письмо **от** указанного адреса — **положить в папку** из этой строки.

Личные правила «положить в папку» нельзя записать через IMAP и через API Яндекс 360 (там только удаление и пересылка на уровне организации). Скрипт открывает сайт Почты в обычном окне браузера и заполняет форму настроек. Пароль, капчу и код подтверждения он не вводит: в открывшееся окно нужно войти самому.

## Как это работает

1. Читает `tablica.xlsx`. Первая строка — заголовки, дальше две колонки: **Название папки** и **Адреса почт**. Пустые строки пропускаются. Повтор одного и того же адреса в одной папке берётся один раз.
2. Запускает Chromium с отдельным профилем в каталоге `.mail-profile`. Сессия остаётся между запусками, поэтому второй раз входить обычно не нужно.
3. Открывает [Яндекс Почту](https://mail.yandex.ru/) и ждёт до 10 минут, пока на экране появится ящик.
4. Переходит в «Правила обработки писем».
5. Для каждого адреса, которого ещё нет на этой странице, нажимает «Создать правило» и заполняет форму:
   - **Если:** От кого → содержит → адрес из таблицы
   - **Выполнить действие:** Положить в папку → папка из таблицы
   - **Название:** `папка: адрес`
6. Сохраняет правило и переходит к следующей строке.

Папки к этому моменту уже должны быть в ящике: скрипт выбирает их из списка и сам не создаёт. Письма, которые уже лежат в ящике, не перекладываются. Чтобы включить пункт «Применить к существующим письмам», запустите скрипт с флагом `--apply-existing`.

Адрес ящика, для которого скрипт пишет подсказку при входе, задан в `create_filters.py` константой `ACCOUNT`.

## Как запустить

Нужны Python 3.10+ и графический экран: окно браузера открывается у вас на компьютере, не на сервере без дисплея.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium
```

Если браузер не стартует из‑за системных библиотек:

```bash
sudo .venv/bin/playwright install-deps chromium
```

Посмотреть, какие правила получатся из таблицы, без открытия почты:

```bash
.venv/bin/python create_filters.py --dry-run
```

Создать правила:

```bash
.venv/bin/python create_filters.py
```

В открывшемся окне войдите в нужный ящик. Когда почта загрузится, скрипт продолжит сам. Повторный запуск пропускает адреса, которые уже видны в списке правил.

Другой файл таблицы:

```bash
.venv/bin/python create_filters.py --xlsx /путь/к/файлу.xlsx
```

Пример строк в таблице:

| Название папки | Адреса почт |
| --- | --- |
| папка1 | yandex1@yandex.ru |
| папка1 | yandex2@yandex.ru |
| папка2 | yandex4@yandex.ru |

## Что не коммитить

Каталог `.mail-profile` — это сессия браузера, в ней остаются cookie входа. Каталог `debug/` — снимки экрана, если форма не заполнилась. Оба каталога указаны в `.gitignore`.
